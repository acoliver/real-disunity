# ABI changes

This directory holds the prose of the Disunity ABI.

- `surface.g.txt` is generated by the build from the exported functions, the C record layouts and the
  error reasons of the crate. The ABI revision is the 32-bit FNV-1a hash of its text. Never edit it
  by hand; when the build reports that it drifted, review the diff and copy the generated file named
  in the message (see `csharp/README.md`, "Explicit binding maintenance").
- Every other file describes one change to the interface. A change adds one file, named for its topic
  (`draw-mesh-batch.md`, not a number), so two changes never edit the same lines. State what the
  change adds, removes or alters in the interface and how the host and the managed side use it.
  Leave the files of other changes alone; a later change that alters the behavior a file describes
  says so in its own file.
- The revision is never written down. A change does not bump a counter, and the manifest
  (`../disunity_interface.json`) lists exports only.
