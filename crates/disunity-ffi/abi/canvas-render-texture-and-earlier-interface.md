# Canvas render textures and the interface before them

disunity_canvas_renderer_texture_write takes a texture kind (0 a stored image identity, 1 a render texture the world holds), so a canvas renderer can draw with a render texture; DisunityUiGraphicInfo and DisunityUiDraw carry texture_kind and a padding word (the draw record grows from 152 to 160 bytes, the graphic info from 16 to 24), and the quad texture of a draw with kind 1 is the render texture id. A slot of a mesh object draws from the slot's world material alone and draws white with texture 0 when it has none; the renderer record keeps no drawn slots, and DisunityDrawnMaterial is the slot record of disunity_presentation_mesh_object. A texture slot of kind 5 names a texture the data names that the engine did not send (a destroyed or empty texture, one the engine cannot store, one the importer did not build), with texture identity 0, which the world reads as no texture and the host's stand-in census reports as not loaded; the graphics snapshot encoding carries it from wire version 17. A mesh renderer holds a property block for each material slot beside the block of every slot, which the shader property calls reach with scope 4 and the target disunity_mesh_renderer_slot_block_target gives; the graphics snapshot encoding carries them from wire version 16. disunity_environment_read and disunity_environment_write move the world's environment lighting (the ambient light and the default reflection, with a set flag for each section) in the 224-byte DisunityEnvironment, and the graphics snapshot carries the environment from wire version 15. A command buffer records a scissor rectangle (disunity_offscreen_enable_scissor and disunity_offscreen_disable_scissor, kinds 20 and 21) and a global depth bias (disunity_offscreen_set_depth_bias, kind 22), which the graphics snapshot carries from wire version 14. DisunityTextureInfo, the record of a stored texture, is 64 bytes: it carries depth (the layers of a 2D array, the six faces of a cube or the slices of a 3D texture), graphics_format, dimension (2 for 2D, 3 for 3D, 4 for a cube, 5 for a 2D array) and a reserved word that is zero. A texture of one or more layers of a layered dimension states its graphics_format, its length is a whole number of layers (a 3D texture with more than one mip level holds its levels one after another, each with its own slices, and need not be), and a 2D texture has depth 0 or 1. DisunityRenderTexture carries auto_generate_mips (1 when the host regenerates the smaller mip levels whenever the texture is drawn into) and a padding word that keeps generation aligned, and disunity_offscreen_generate_mips records a request to fill the mip levels of a render texture with more than one level, which a take reports as kind 19 and the graphics snapshot carries as a GenerateMips record. A command buffer records a mesh draw with an instance count (disunity_offscreen_draw_mesh_instanced), which the graphics snapshot encoding carries from wire version 12, and a material binds a compute buffer to a property name as a structured buffer through disunity_material_set_buffer, which the graphics snapshot copies with the draws that use the material. A command buffer records a viewport, the rectangle in pixels of the bound targets that the draws after it cover, and the offscreen work list carries it as kind 18. DisunityOffscreenWork carries target_kind, so a recorded blit or texture copy writes a render texture (0) or the temporary render texture of a property name id (1), and a texture of kind 4 names a temporary render texture by its property name id as a blit or copy source or a global that recorded work sets. A camera has target buffers (one to eight color render textures and an optional depth render texture), set and read by two camera calls that take the place of a single target texture, and disunity_offscreen_setup_camera takes the buffers the camera had when the script set it up. DisunityUiDraw carries distance_mode (0 coverage, 1 fill, 2 outline, 3 glow), distance_spread in atlas pixels, distance_radius in physical screen pixels and effect RGBA; signed-distance records require textured affine text quads and validated style parameters. DisunityUiDraw carries an explicit corner_colors_present flag (0 white, 1 explicit) and sixteen linear straight-alpha RGBA corner channels in bottom-left, bottom-right, top-right, top-left order, multiplied by the common tint. Triangles use the first three colours. Channels must be finite and in 0..=1. DisunityRenderTexture carries the texture's dimension (2D, 3D, cube, 2D array or cube array) and volume depth (slices, layers or cube-array faces), and render textures in the graphics snapshot carry both. DisunityUiDraw kind low bits 0 mean a graphic quad, 1 means text coverage, and 2 means a graphic triangle using the first three DisunityQuad corners and all three top-row-origin triangle UV pairs. Bit 2 enables scene-depth testing using non-reversed raster depth in the corners. Quad graphics and text have zero triangle UV fields. Managed CanvasRenderer meshes and native annotations share this presentation representation. The Camera record carries perspective lenses, culling masks, viewports, render settings and custom matrices, with two matrix calls; a native 3D Light component, a native CanvasGroup component, a native CanvasRenderer component (with material calls), and native MeshRenderer (also SkinnedMeshRenderer) and MeshFilter components each have their own record and calls. Batch construction, object wake and body position constraints are calls of the world, and canvas scale has its own calls outside the Canvas record, so a canvas can scale with the screen as a CanvasScaler does. The interface also carries native shaders, materials, shader properties and keywords, render textures, world materials and property blocks on mesh renderers, recorded offscreen work, every mesh channel and sub-mesh topology for the host, and a sampler for each stored texture and render texture; for the compute work scripts record, compute shaders, compute buffers, kernel bindings, recorded dispatches and a synchronous GPU flush that a host registers a callback for, on one world or as the default of worlds made later. It carries pixel reads of a render texture (a request for a rectangle, the host's write of its texels and the script's take), renderer lists (two calls that turn a culling result into a drawing list or a shadow caster list, and a call that records the draw of a list), and a view and projection change that a command buffer records for the draws after it. It carries the lights of a prepared frame (a count, and a read of each light's settings, object identity and matrix to the frame's view basis) and the renderShadows setting of the camera a prepared frame presents. A command buffer records a procedural draw: a material's passes over a triangle or line list of vertices its shader makes from the vertex and instance index, with no mesh. disunity_world_advance_teardown is an advance for a host that is tearing the world down: it runs the OnDisable and OnDestroy messages that destruction has queued, and the asset cleanup, and runs no Start, fixed step, Update, coroutine, delayed task, LateUpdate or render phase and leaves the clock and frame count unchanged. A command buffer's global value, array or keyword is a direct write of the world's global state (the disunity_shader_* calls), which the world orders among the take's offscreen records, a write after the last record included; the one global a command buffer records is a texture, through disunity_offscreen_set_global_texture, for the host to set when it reaches the record, because a temporary render texture has no identity that outlives its take.
